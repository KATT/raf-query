# Per-client typed `meta`, bound once per app, with no bundle penalty (human; names agent)

- **(human)** `meta` stays typed per client: a client's root is its links and features, and each declares the `meta` fields it reads ([links-features-meta.md](./links-features-meta.md)). An app binds the root once, and factories never name it. Binding must cost nothing in apps that don't use every builder.
- **One binder per builder**, each separately importable: `bindQueryOptions<Client>()`, `bindInfiniteQueryOptions<Client>()` (core), `bindUseQueryClient<Client>()` (react). `Client` is `typeof makeQueryClient` or the client type (`RootOf`). An app binds them in its own `raf.ts` and imports the builders from there. A binder returns the plain function, cast to a type with the root fixed (`QueryOptionsBuilder<TTypes>`, `InfiniteQueryOptionsBuilder<TTypes>`, `() => QueryClient<TTypes>`). The binders add 22 B gzip to an app that binds `queryOptions` and `useQueryClient`, and that app's bundle has no paging code ([bundle-size.md](../bundle-size.md)).
- **The root is a phantom on the built options**, `"~root"?: RootTag<TTypes>` on `QueryOptions`. `RootOfFactory` (and so `ClientFor` and every verb) reads it. An unbound builder's root is `DefaultTypes`, which verbs treat as any root. Users never write the field: it isn't on the input type.
- **`queryOptions` is a `const` typed `QueryOptionsBuilder<DefaultTypes>`**, so its overloads are written once and the bound builder reuses them. Its value is a generic arrow (`<TOptions>(options: TOptions) => options`), assigned without a cast: an `as` cast on the arrow keeps parentheses in the minified output (+5 B), and a function aliased by a `const` keeps the alias (+10 B).
- **(agent) Names: `bind*`.** The proposal was `*For` (`useQueryClientFor`). A binder whose name starts with `use` reads as a hook to the Rules of Hooks lint and the React Compiler, and it's called at module level, so `bindUseQueryClient` can't start with `use`; `bind` then names all three the same way. `bindUseQueryClient` lives in `bind.ts`, which has no `"use client"`, so a `raf.ts` that a server component imports can call it.
- Lost: `def: defType<typeof makeQueryClient>()` in every factory (typos in `meta` compiled wherever it was left out, and `useQueryClient()` returned a client of any root); `createRoot()` returning `{ queryOptions, infiniteQueryOptions, useQueryClient }`, whose object keeps every builder in every bundle; a global `Register`, which allows one root per program.
- The example apps keep the plain builders: none of them sets `meta`, and binding would add a file that checks nothing.
- Where: `packages/core/src/options.ts`, `infinite.ts`, `root.ts`; `packages/react/src/bind.ts`; types in `packages/core/src/types.test-d.ts` and `packages/react/src/hooks.test-d.tsx`; fixture `tooling/bundle-size/fixtures/bound.tsx`.
