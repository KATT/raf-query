# Isomorphic requests: forward cookies, swap transports at build time (human asked, agent designed)

Human: the Next.js docs must explain how a factory's request works on both server and browser (headers, cookies), and the examples follow the pattern so they fork as a real starting point.

- **No raf-query API for it.** A factory's `queryFn` closes over a transport module. In Next.js App Router it runs in exactly two places: server components (`getQueryClient`) and the browser. A server render starts no request ([server-renders-start-no-requests.md](./server-renders-start-no-requests.md)), so client-component SSR never calls it, and nothing needs the app's own origin. Lost: a per-client context passed to `queryFn` (it adds a concept, and the client components' client is made in a client component, where the server's transport can't go).
- **The API authenticates from its own cookies.** The browser sends them on same-origin `fetch`; the server forwards the page request's `cookie` header to its in-process call. Same as tRPC (`createTRPCContext` from `headers()` / the route handler's `req`) and oRPC (`createRouterClient(router, { context: async () => ({ headers: await headers() }) })`). Forward only `cookie` (or `authorization`), not every header. Lost: app code reading cookies on each side and re-sending them as custom headers (an `x-db-latency` header): a real session can be `HttpOnly`, so `document.cookie` can't see it.
- **Swap by export condition, not `typeof window`.** Next.js resolves `react-server` for server components (package `imports` too, Turbopack dev and build), so `#forwarded-headers` → `forwarded-headers.server.ts` can import `next/headers` statically; `default` (browser and client SSR) returns `{}`. `@examples/api/client` swaps in-process / HTTP with `browser` / `default`, shared with Start. A runtime check with a dynamic import would put the server module in a browser chunk. oRPC's `globalThis.$client` is the other way to get there.
- **Start**: `createIsomorphicFn().server(() => getRequestHeader("cookie"))`, `.client(() => ({}))`, since loaders run during SSR.
- Files: `examples/nextjs/src/forwarded-headers{,.server}.ts`, `examples/tanstack-start/src/forwarded-headers.ts`, `examples/.shared/api/src/app.ts` (`getCookie`). Docs: `www/content/react-server-components.md` and `tanstack-start.md` ("Server and browser requests"), with samples in `www/samples/nextjs/src/api-fetch{,.server}.ts` (`#api-fetch`) and `www/samples/tanstack-start/src/forwarded-headers.ts`.
