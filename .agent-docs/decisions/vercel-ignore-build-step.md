# Vercel skips a build by diffing from the last deployment (human asked)

- `ignoreCommand` in every `vercel.json` installs `@tooling/vercel-ignore` (`pnpm install --frozen-lockfile --prod --ignore-scripts --filter …`: about 14 packages, Effect and its Node platform) and runs its `src/bin/ignore.ts` from the project's root directory. It's in Effect (human, see `effect-everywhere.md`). `--prod` keeps the root's dev tooling out. `--ignore-scripts` skips the root `postinstall`, which needs that tooling. Vercel's full install afterwards still succeeds.
- It watches the project, every workspace package it reaches through `workspace:` dependencies (any dependency field, transitively, from `pnpm-workspace.yaml`'s globs), and the root install inputs (`package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml` for catalog and overrides, `.npmrc`, `patches`). Deriving the list keeps it from drifting: the hand-written lists missed `@examples/kit` for `www` and the catalog.
- It diffs `$VERCEL_GIT_PREVIOUS_SHA..HEAD`, not `HEAD^..HEAD`. A push of several commits whose tip only touches docs skipped the example apps even though an earlier commit changed `packages/`.
- `VERCEL_GIT_PREVIOUS_SHA` is the last successful deployment on the project and branch, so skipped deployments don't move it. It is empty on a branch's first deployment, which is most PRs (one push). Then it fetches `main` (depth 100, public HTTPS URL) into Vercel's shallow clone and diffs from `git merge-base FETCH_HEAD HEAD`. Building on every first deployment rebuilt all four apps for a `www`-only PR (#154). On `main` itself an empty SHA builds.
- If the SHA isn't in Vercel's shallow clone, as after a force-push, `git diff` exits 128. Vercel documents only 0 (skip) and 1 (build), and force-pushed PR branches failed every deployment within about 15 seconds of starting. So every failure (install, fetch, merge-base, diff, a git command's non-zero exit) exits 1 and builds. Building too often beats skipping one that changed.
- Lost: `turbo query affected` (no Turborepo here); `HEAD^` (only the tip commit); a Node-built-ins script that needs no install (human wants Effect).
