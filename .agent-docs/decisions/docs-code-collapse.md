# Folded code lines (human asked)

- The homepage sample folds the JSX and the `Comments` function (human): the loader and the typed `useQuery` stay visible, and each folded range opens and closes. Every line doesn't have to be on screen to see the point.
- Folds are Expressive Code's collapsible sections (`rehype-expressive-code` and `@expressive-code/plugin-collapsible-sections`). A fence marks them with `collapse={4-9}` (and more ranges, comma-separated). The style is `collapsible-start`: closed, the summary says “N collapsed lines”; open, that label hides and a collapse icon stays on the summary, and a second click closes the lines. Copy includes the lines. Tailwind's `collapse` utility and the prose `details` box are reset inside the code block so that icon stays visible.
- The line numbers are the lines Expressive Code highlights, which is the code left after Twoslash's `// ---cut---` and `// ^?`. Twoslash still runs on TypeScript 6, with the same virtual project, and then the fold wraps those lines. A pinned type is rendered inside its line, so it opens and closes with that line.
- Lost: comment markers (`// ---collapse---`), which named the range without counting lines, and Expressive Code's default `github` style, which cannot close again.
