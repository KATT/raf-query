# Demo browser windows slide between pages (human asked)

- A link in a demo window slides the page in from the right, Back from the left, Reload cross-fades (`demo-forward` / `demo-back` / `demo-reload`, animated in `www/src/styles.css`). Only the window animates; the page around it updates in place.
- `DemoBrowser` (own state) uses React `<ViewTransition>`: `go()` calls `addTransitionType` inside its `startTransition`, and the boundary's `default` maps each type to its class and everything else to `"none"`. Without the `"none"`, React would name the window for the demos' own `startTransition`s (invalidate, mutate) and cross-fade the pending UI they exist to show — and every such update would start a document view transition.
- `DemoRouter` is a nested TanStack Router, whose commits are synchronous (`useSyncExternalStore`), so it uses the router's `defaultViewTransition` with those types. Direction comes from the memory history's own subscriber (`BACK` vs `PUSH`). Names must be unique per document and several demos can share a page, so `onBeforeNavigate` moves a `data-demo-navigating` marker to the window that navigated and CSS names only that one. Its root snapshot is hidden for these types: the window changes height, and cross-fading the shifted page ghosted it.
