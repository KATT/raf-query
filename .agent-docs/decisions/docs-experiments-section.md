# Docs: an Experiments section, with standalone demos (human asked, agent designed)

Human: interactive docs for the effect-query experiment ([experiment-effect-query.md](./experiment-effect-query.md)), in an "Experiments" nav group, with a page clearly marked experimental.

- **Experiments is the sidebar's last section** (`sections` in `www/src/site.ts`). Its page's title says "(experimental)", and the page opens with a `[!WARNING]` callout: not part of raf-query, unpublished, its API will change.
- **The page's code is a sample package**, `www/samples/effect-query` (`@samples/effect-query`), like the other guides' ([docs-sample-packages.md](./docs-sample-packages.md)): `src/{api,client,queries,boundaries}` are the app, and `src/docs/effect-query-boundaries{,.errors}.tsx` hold the page's blocks. Twoslash shows the compiler's own errors (`// @ts-expect-error -- 2345: …` → `// @errors: 2345`) and pins the plain data type with `// ^?`. The sample depends on `@raf-query/experimental-effect-query` through the workspace.
- **Standalone demos**: `defineStandaloneDemo({ Component, title, hint })` in `www/src/demo-kit/define.ts`, rendered by `StandaloneDemoFrame` (same box and title as `DemoFrame`, no kit client, network or cache panel). The effect-query demo brings its own: an in-memory Effect RPC server (`RpcServer.makeNoSerialization`) behind the real package, chaos switches, and an event log fed by the root's `onCaught`. Lost: `defineDemo`, whose fake server, client and panels are raf-query's.
- The demo's files in `www/src/demos/effect-query-boundaries/` are copies of `.experimental/effect-query/demo/src/`, except that the components use the shared UI kit's `cn` and the log is fed by `onCaught` instead of `createRoot`'s `onCaughtError`. Its state (chaos, log) is module-global, like the demo app's, so it survives remounts but is shared if the page embedded it twice.
