# Docs search: MiniSearch, ranked by name, body text loaded apart (agent)

- Ported from tRPC's docs site (trpc/trpc#7958, `www/src/content/search.ts` there), adapted: no versions, no API reference tier, no Algolia, no sidebar nesting (a heading's trail is its page and `h2`). `www/src/content/search.ts` is pure; the dialog (`components/search.tsx`) and `/search` (`routes/search.tsx`) only call it.
- Ranking: what's named for the query first (a page's title or slug, then a heading's text: exactly, as a prefix, then as whole words, give or take a plural or `-ing`), pages above headings; then the rest by MiniSearch's score. Typos only in words of four letters or more. `src/content/search-ranking.test.ts` pins the top result of real queries over `www/content`; when a docs change moves one, check the new top result is right before updating the test.
- Body text: unlike tRPC's, search reads each section's text (code blocks and demos left out). `build/markdown.ts`'s `searchSectionsOf` shares the render's pipeline up to the headings' ids, without Shiki, so ids match and it's quick. It's served as `virtual:docs-search-text` (~130 kB, ~42 kB gzip), a chunk the dialog loads on hover, focus or open (`content/search-text.ts`); until then search finds names and descriptions. MiniSearch itself (~7 kB gzip) is in the main bundle. Lost: the text in the manifest (every page would ship it); a prebuilt serialized index (bigger than the text).
- `?q=` is validated on the root route (`search-page.ts`), opens the dialog on any page, and is written back once typing pauses. The site is prerendered, so `/search` is the empty form; the query field is empty until hydration (`useHydrated`) so the static HTML always matches. `www/src` bans `useEffect`: URL sync adjusts state during render, the text loads through `useSyncExternalStore`, and the shortcut listener lives in a ref callback.
- Tests: search ranking and recent results are logic, not presentation, so `vitest.config.ts` runs `src/**/*.test.ts` too ([docs-site-no-ui-tests.md](./docs-site-no-ui-tests.md) still holds for UI).
