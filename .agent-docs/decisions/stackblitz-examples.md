# Examples on StackBlitz from a generated branch (human asked, agent designed)

- Human: "i want the examples deployed on stackblitz", like tRPC, which opens one folder of the repo as the project root and links it from each example's README.
- tRPC's examples only depend on published `@trpc/*` (written `npm:@trpc/x`, linked locally by `linkWorkspacePackages`), so `stackblitz.com/github/trpc/trpc/tree/main/examples/<x>` works from `main`. Ours also import the private `@examples/ui` / `@examples/db` from `examples/.shared/`, which a single folder doesn't contain. So `scripts/stackblitz-examples.ts` writes standalone copies, and `.github/workflows/stackblitz.yaml` pushes them to the `stackblitz` branch. Links point at `tree/stackblitz/examples/<app>`.
- In each copy: `shared/{api,db,ui}` are `file:` dependencies (app source is unchanged, CSS `@import "@examples/ui/globals.css"` still resolves), with their `devDependencies` removed, because npm installs a linked package's dev deps, which would add a second React. `workspace:*` `@raf-query/*` become the version in `packages/*/package.json`.
- The workflow runs on `workflow_run` of Release, not on push: after a release that version is on npm. It installs and builds each copy with npm before pushing, so a copy that doesn't build never reaches the branch. Only the `main` apps are copied. The `.experimental/` ones depend on an unpublished package.
- WebContainers limits, handled in the copies only: the `vp` CLI is native, so scripts use `vite` (the workspace overrides `vite` with Vite+, standalone gets plain Vite 8). Turbopack has no WebAssembly build, so dev is `next dev --webpack`. `.stackblitzrc` sets `installDependencies: false` and `startCommand: "npm install && npm run dev"`: StackBlitz's own installer (`.wxt/node_modules`) broke AsyncLocalStorage-based request context in both frameworks ("No Start context found", "Expected workStore to be initialized").
- Lost: separate `examples-*` repos per app (tRPC's `subtree.yml`; needs repos and deploy keys), and making the apps self-contained on `main` (would undo the shared `examples/.shared/` packages, a human decision).
