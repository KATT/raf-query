# `QueryCache.Filter` (agent)

- **`QueryCache.Filter` is `{ queryKey?, exact?, type?, stale?, fetchStatus?, predicate? }`**, TanStack's `QueryFilters` field for field, evaluated only in `matcher` (`cache.ts`) in `matchQuery`'s order: key, `type`, `stale`, `fetchStatus`, then `predicate(query)`. `queryKey` is optional and `{}` matches everything, like TanStack's `invalidateQueries()`; the filter argument itself stays required, so selecting the whole cache is explicit. `handle.input` is `undefined` on hydrated-only entries (hydration has keys, not inputs).
- **`type`** is `Entry.isObserved` (subscribed readers), what `invalidate` and focus refetch already go by; TanStack's `isActive()` also requires an enabled observer, and raf-query has no `enabled`. **`stale`** is `isStaleUnsafe`, staleness as of now (`state.isStale` only updates while read), so a server cache matches by `staleTime` too, though its verbs only refetch what `invalidate` marked. **`fetchStatus`** is `"fetching" | "idle"` on `state.isFetching`: raf-query has no `"paused"` (a retry waiting for the network stays `"fetching"`).
- Lost: `predicate`-only (the fields were `predicate` with `observerCountUnsafe`, `isStaleUnsafe`, `getUnsafe(query).isFetching`). The fields cost one line each and save every TanStack user that rewrite.
