The concept page every integration builds on (Server rendering and hydration) is a guide. Lost: a "Server rendering" section, first mixing that page with framework setup, then holding it alone.

The integration needs only a bundler that resolves `react-server` ([rsc-frameworks-test.md](./rsc-frameworks-test.md)); sections built on Next.js APIs (`useLinkStatus`, `next/headers`, Route Handlers, server actions) say so. `/docs/nextjs` and `/docs/nextjs.md` 308 to it (`www/build/vercel-output.ts`), for links that use that slug.
