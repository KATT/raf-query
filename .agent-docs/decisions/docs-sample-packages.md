# Docs samples compile in workspace packages in `www/samples` (human)

- **Two sample apps, each a package** (human: "an actual thing with package.json inside of www/", "one for nextjs and one for tanstack"): `www/samples/tanstack-start` (`@samples/tanstack-start`) and `www/samples/nextjs` (`@samples/nextjs`). `www` lists each as a `workspace:*` devDependency. Lost: `examples/.shared/*` as the home (the human's first idea), since only the docs use these apps and `examples/` holds runnable demos.
- **One TanStack Start app for every TanStack sample** (agent): the quick start, the TanStack Start page and every inline block share `tanstack-start`, so its `router.tsx`, `routes/__root.tsx` and `queries.ts` are each one file. The quick start shows the same router as the TanStack Start page, and its factories are the `todos` region of `queries.ts`, which wraps the region's own imports, so the file has a second import from `@raf-query/react` and `./api.ts`.
- **Each app declares what its blocks import** (agent): blocks compile with the app as Twoslash's `vfsRoot`, so imports resolve from the app's `node_modules`. A library a block imports goes in that app's `package.json`, not `www`'s.
- **`// @filename` is a path from `www/samples`** (agent): `tanstack-start/src/routes/posts.$slug.tsx`. `build/markdown.ts` picks the app from it and rewrites it to the path in the app. A block without one is a file of the page's `sampleApp`, `tanstack-start` by default. One rule covers included blocks (named by `build/snippets.ts`) and route-defining inline blocks.
- **Typecheck is each package's own `tsc`** (agent): the root `pnpm typecheck` filters `./www/samples/*`, which replaced `build/typecheck-examples.ts`. Each app has a standalone `tsconfig.json` (no shared base) with `~/*` → `./src/*`.
- **The Effect pages have their own app, `tanstack-start-effect`** (agent): the issue tracker of "Using Effect", with an in-memory `IssueApiLive`. A third app keeps Effect out of `tanstack-start`, which the quick start shows ("Using raf-query must not require knowing Effect"). The pages set `sampleApp: tanstack-start-effect` in their frontmatter, so their inline blocks compile there without a hidden `// @filename` each. "The whole picture" includes its files.
- **`posts.tsx` and `settings.tsx` are placeholder routes** (agent): pages write their own versions as `// @filename` blocks, and the route tree needs the route to exist.
